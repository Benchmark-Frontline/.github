# Community space

[中文](./README.zh-CN.md)

Benchmark Frontline is first and foremost a place for peer exchange and shared learning. This page explains how the community moves from conversation to deeper exploration without turning participation into assignments.

## How the community moves

1. **Open conversation** — Share a question, a paper, a case, or an observation in GitHub Discussions or the WeChat group.
2. **Topic proposals** — When a question attracts interest, it can be proposed as a topic circle.
3. **Topic circles** — A small, voluntary group spends around four weeks reading, discussing, comparing notes, or trying an optional reproduction.
4. **Shared memory** — With participants' consent, useful links, notes, or code can remain here so later conversations can build on them.
5. **Reflection and next topics** — The group reflects briefly and returns to open conversation.

Participation is voluntary. There is no fixed workload and no requirement to produce a deliverable.

## Topic board

This is a lightweight public index, not a task board.

| Status | What it means |
| --- | --- |
| Open for discussion | A question is being explored in the community. |
| Gathering interest | People are deciding whether to form a topic circle. |
| Topic circle | A voluntary small group is currently learning and discussing together. |
| Continued reference | A past conversation that may be useful to revisit. |

There are no active topic circles yet. The first topic will be selected through an open community call for ideas.

## How to join

- Start or reply to a discussion.
- Share a useful paper, example, method, or question.
- Express interest when a topic circle is proposed.
- Suggest a topic you would like to explore with peers.
