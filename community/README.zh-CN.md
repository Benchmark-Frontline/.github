# 社区空间

[English](./README.md)

Benchmark 阵线联盟首先是一个同行交流、共同学习的空间。这一页说明：讨论如何自然走向更深入的探索。

## 社区如何运转

1. **自由讨论** —— 在 GitHub Discussions 或微信群分享问题、论文、案例与观察。
2. **主题征集** —— 当一个问题引起持续兴趣时，可以提出成为专题。
3. **专题小组** —— 一个小型、自愿参与的小组用约四周时间共同阅读、讨论、交换经验，或可选地复现一个公开案例。
4. **共同记忆** —— 征得参与者同意后，有用的链接、笔记或代码会留在这里，供后续讨论接续。
5. **复盘与下一轮** —— 简短回顾后，再回到开放讨论并征集新主题。

参与完全自愿且灵活，大家可以按自己感兴趣的方式加入。

## 如何参与

- 发起或回复一个讨论；
- 分享一篇有用的论文、案例、方法或问题；
- 在专题提议下表达兴趣；
- 提出一个希望与同行共同探索的主题。
