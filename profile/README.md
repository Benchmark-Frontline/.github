# Benchmark Frontline

一个面向模型评测、数据与 AI 研究实践的开放交流社区。

我们希望让研究者、学生、工程师和所有对模型评测感兴趣的朋友，在这里一起讨论问题、交流论文与方法、分享技术经验和实践心得，并沉淀可复用的开源成果。

## 我们关注

- 模型评测与 Benchmark 设计
- 数据质量、标注与数据研究
- 论文讨论与技术分享
- 开源工具、数据集与复现实验
- 社区协作与实践交流
