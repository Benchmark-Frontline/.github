# Benchmark 阵线联盟

[English](./README.md)

一个面向模型评测、数据与 AI 研究实践的开放同行交流社区。

我们欢迎研究者、学生、工程师和所有对模型评测感兴趣的朋友，一起讨论问题、交流论文与方法、分享技术经验和实践心得。

## 我们关注

- 模型评测与 Benchmark 设计
- 数据质量、标注与数据研究
- 论文讨论与技术分享
- 开源工具、数据集与可复现研究实践
- 社区讨论与共同学习

## 如何参与

- **[讨论区](https://github.com/orgs/Benchmark-Frontline/discussions)** —— 问题、论文、案例与观点。
- **[社区空间](../community/README.zh-CN.md)** —— 了解讨论与专题小组如何运转。
- **加入 / 联系我们** —— 可先从发起讨论开始；如需申请加入组织或咨询协作，也欢迎邮件联系。
